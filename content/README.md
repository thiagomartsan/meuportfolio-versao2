# Conteúdo TM21

A fila editorial existe para impedir produção aleatória. Cada pauta deve ter intenção, página relacionada, CTA e necessidade de evidência definidos antes da redação.

Fluxo futuro: pesquisa → pauta estruturada → geração assistida por IA → validação → publicação → sitemap → Search Console → aprendizado.

Não publicar automaticamente conteúdo regulado, afirmações de mercado ou estatísticas sem revisão e fonte atual.


## Taxonomia editorial do blog (V20)

Categorias públicas atuais:
- SEO
- Processos
- Pricing
- Posicionamento digital

Frentes futuras previstas, ativadas somente quando houver conteúdo suficiente:
- Ferramentas digitais
- Automação
- IA aplicada
- Produto digital

A regra é não publicar filtros vazios. Uma categoria nova só entra na interface quando houver pelo menos um conteúdo útil e, idealmente, uma pequena sequência editorial planejada. O eixo continua sendo tecnologia aplicada a negócios, sem transformar o blog em conteúdo técnico de TI.
